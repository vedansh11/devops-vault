# What is Cloud Computing

## Definition

Cloud computing is a model where computing resources such as **servers, storage, networking, databases, and software** are delivered **on-demand over a network (typically the Internet)** instead of being owned and maintained locally by an organization.

Users can provision, scale, and release resources dynamically and pay only for what they consume.

---

## How Computing Worked Before Cloud (On-Premises)

Before cloud computing, organizations operated their own **on-premises data centers**.

Typical setup:
- Purchase physical servers from vendors (IBM, HP, Dell)
- Install servers in a data center
- Manage power, cooling, cabling, and networking
- Manually provision servers for applications
- Hire dedicated system administrators
- Perform hardware upgrades and replacements

### Limitations of On-Premises Infrastructure
- High upfront capital expenditure (CapEx)
- Underutilized resources (CPU, RAM, storage waste)
- Slow provisioning (weeks or months)
- Difficult scaling during traffic spikes
- Continuous maintenance and operational overhead
- Hardware failures directly impact availability

---

## Virtualization: Foundation of Cloud

### What is Virtualization

Virtualization is a technology that allows multiple **virtual machines (VMs)** to run on a single **physical server** using a software layer called a **hypervisor**.

Examples of hypervisors:
- VMware ESXi
- KVM
- Xen

### Benefits of Virtualization
- Better hardware utilization
- Isolation between workloads
- Faster provisioning of servers
